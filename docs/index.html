rayim

🚀 Fast image compression for a large number of images, powered by the Ray library.

Get started View on GitHub

Why rayim?

⚡

Parallel by default

Distributes compression across all your CPU cores with Ray — no setup required.

📉

~45% smaller

Typical JPEG output is roughly half the size with no visible quality loss.

🗂️

Files & folders

Point it at single files, whole directories, or many of each at once.

🔧

Flexible

Resize, convert to JPEG, optimize, replicate directory trees, and more.

Installation

pip install rayim

Usage

# Compress a single file
rayim foo.jpg
# 🚀 foo.jpg: 1157. kB ==> 619.9 kB (-46.4%) | 0.07s

# Compress a folder, writing output to ./compressed
rayim foo/ -o compressed

# Resize to 800x600 and convert to JPEG
rayim foo/ -s 800 600 -j

Run rayim -h to see every option — quality, subsampling, optimize, keep-date, and more.
